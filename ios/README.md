# Middle Corridor — iOS

Нативное приложение (SwiftUI, iOS 17+) поверх того же `/api/v1`, что и веб-карта.
Видение и решения — [`docs/IOS.md`](../docs/IOS.md).

```
ios/
  project.yml   проект Xcode (XcodeGen); .xcodeproj генерируется, в git его нет
  MCCore/       Swift Package без UI: модели /api/v1, клиент, разбор ссылок,
                подписи RU/EN, «Мои грузы»; тесты — swift test, без симулятора
  App/          SwiftUI-экраны поверх MCCore
  UITests/      смоук-тесты экранов на фейковом API (-mc-fake-api)
```

## Один раз на Маке

```bash
brew install xcodegen python@3.11
```

Если `xcode-select -p` показывает `/Library/Developer/CommandLineTools`, то
`xcodebuild`/`simctl` не найдутся. Нужно либо `sudo xcode-select -s /Applications/Xcode.app`,
либо `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` в сессии.

## Каждый день

```bash
cd ios && xcodegen generate                 # после pull и правок project.yml
cd ios/MCCore && swift test                 # логика, ~секунды
cd ios && xcodebuild -scheme MiddleCorridor -destination 'platform=iOS Simulator,name=iPhone 17' build
cd ios && xcodebuild test -scheme MiddleCorridor -destination 'platform=iOS Simulator,name=iPhone 17' -resultBundlePath build/ui.xcresult
xcrun xcresulttool export attachments --path build/ui.xcresult --output-path build/shots   # скриншоты смоука
open ios/MiddleCorridor.xcodeproj           # или Xcode → Run
```

## Бэкенд для демо

Из корня репозитория, синтетика без Postgres и ключей:

```bash
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
MOCK_DATA=true DEMO_CONTROL=true .venv/bin/python -m app.main   # слушает 0.0.0.0:8000, с пультом демо
```

По умолчанию приложение ходит на публичный демо-сервер `https://middle-corridor-weld.vercel.app`
(тот же `MOCK_DATA`, но пульт демо там выключен) — Мак не нужен. Для пульта демо (мок-время,
«Следующий шаг») — свой бэкенд с `MOCK_DATA=true DEMO_CONTROL=true`: симулятор — `http://localhost:8000`, iPhone — IP Мака
в той же Wi‑Fi: `ipconfig getifaddr en0`. Адрес — в разделе для разработчика: Настройки →
долгое нажатие на строку версии → секция «Сервер» (там же пульт демо; обычному пользователю
этот раздел не виден). На запрос «Локальная сеть» ответить «Разрешить».

«Поделиться» в карточке груза отдаёт https-ссылку на веб-карту `<сайт>/?s=<номер>`, а не
`mcstatus://` (его мессенджеры не делают ссылкой). Адрес сайта — ключ сборки `MC_SHARE_BASE_URL`
в `project.yml` — `https://middle-corridor-weld.vercel.app`.

## Демо для ведущего (пульт времени)

Бэкенд с историей груза MC-26-0398 и переводом часов (только локально, не на Vercel):

```bash
MOCK_DATA=true DEMO_CONTROL=true .venv/bin/python -m app.main
```

- История 0398: ждёт парома в Актау («риск шторма») → шторм, погодный запрет, очередь
  «2–3 дня, до 5» → паром «Turkestan» → Алят → … → Констанца, доставлен; через ~10 суток
  мок-времени начинается заново.
- Пульт: Настройки → долгое нажатие на строку версии → секция «Демо»: «+6 ч», «+1 д»,
  «Следующий шаг», «Сброс истории». Тем же жестом пульт прячется.
- На показе: долгое нажатие **двумя пальцами** в любом месте приложения — следующий шаг
  истории; на экране ничего не появляется, только лёгкая вибрация. (Не тап тремя пальцами:
  это системный жест «Отменить», iOS показала бы баннер.)
- Без сети приложение показывает последние данные из кэша с плашкой «Нет связи — данные от …».

## Уведомления, Live Activity, виджет (неделя 3)

- **Уведомления** — локальные, без APNs: приложение сравнивает данные до и после каждого
  обновления (открытие, обновление списка, раз в минуту на экране, шаг пульта) и сообщает:
  шторм в порту на пути груза (включая порт, где он стоит), новое событие, рост задержки
  на 3 ч и больше, сдвиг прогноза очереди на 12 ч и больше. Первая загрузка груза молчит.
  Разрешение спрашивается после первого добавленного груза; виды — в Настройках.
- **Демо:** в пульте «Задержка уведомлений» (по умолчанию 5 с) — нажали «Следующий шаг»
  или жест, заблокировали телефон, уведомление приходит на экран блокировки.
- **Live Activity** — кнопка «На экран блокировки» в карточке груза: плечо («Курык →
  паром «Barda» → Баку (Алят)»), статус цветом, ETA; Dynamic Island. Обновляется
  приложением, «Доставлен» — закрывается через минуту.
- **Виджет** (малый и средний): груз и адрес сервера — в «Изменить виджет». На симуляторе
  виджет без настроек берёт груз и сервер из приложения (App Group); на iPhone с
  бесплатным Apple ID App Group нет — номер и адрес вводятся в настройках виджета.
- **Предпросмотр** — пульт → «Предпросмотр виджета и Live Activity»: как это выглядит,
  без добавления виджета на домашний экран.
- **Пуш на симуляторе** (настоящий системный баннер, как от сервера):

```bash
xcrun simctl push booted com.malakhouski.mcstatus ios/demo/storm.apns   # event / delay / queue
```

## Неделя 5: точность, вилка ETA, карта

- **Точность прогноза** (вкладка «Коридор», экран порта): `/api/v1/accuracy`; в демо-режиме —
  синтетическая история штормов (тот же расчёт POD/FAR, что в боевой сверке), с пометкой
  «демо-данные».
- **Вилка ETA и «Почему задержка»** в карточке: поля `eta_latest` и `delay_breakdown` API.
  Пока груз в очереди, ETA считается от прогноза очереди.
- **Карта как в Telegram:** превью в карточке → по нажатию на весь экран (щипок, «Где груз»,
  «Весь маршрут»); на «Коридоре» карта закреплена сверху, развернуть — кнопкой.

## Видео демо и сценарий ведущего

- Сценарий показа (≈ 2 минуты), подготовка и запасной план — [`docs/IOS-DEMO.md`](../docs/IOS-DEMO.md).
- Видео с симулятора — сценарий ведёт `UITests/DemoScenarioTests`, время переводит сам тест
  через `/api/v1/demo/clock` (пульт в кадр не попадает); нужен бэкенд с `DEMO_CONTROL=true`:

```bash
ios/scripts/record_demo.sh            # → ios/build/demo.mp4
```

- Иконка «Каспий» (силуэт моря, рельсы с двух берегов, переправа Актау → Алят, паром) рисуется
  скриптом в трёх вариантах для iOS 18+ — обычный (без альфа-канала), тёмный и тонированный (без фона):
  `swift ios/scripts/make_icon.swift ios/App/Assets.xcassets/AppIcon.appiconset/icon-1024.png any`,
  то же с `icon-dark-1024.png dark` и `icon-tinted-1024.png tinted`. PNG в репозитории отрисованы
  с той же геометрией вне Мака — после первого запуска скрипта сверить глазами.
- Скриншоты тёмной темы в UI-тестах — аргумент запуска `-mc-appearance dark` (только Debug).

## Настоящий iPhone: подключение и финальный прогон

Нужно: iPhone с iOS 17+, кабель, Apple ID (бесплатного хватает), Xcode на Маке.

### 1. Подключить и подписать (один раз)

1. iPhone по кабелю к Маку → на телефоне «Доверять этому компьютеру» → код-пароль.
2. **Режим разработчика** (iOS 16+, без него Xcode не запустит приложение):
   Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл →
   перезагрузка → «Включить». Пункт появляется после первого подключения к Xcode.
3. Xcode → Settings → Accounts → «+» → Apple ID.
4. Проект: `cd ios && xcodegen generate` → открыть `MiddleCorridor.xcodeproj`.
   Таргеты **MiddleCorridor** и **MiddleCorridorWidgets** → Signing & Capabilities →
   Team: Personal Team (оба). `xcodegen generate` сбрасывает Team — выбирать заново
   после каждой генерации проекта.
5. Если Xcode пишет, что bundle ID занят: поменять префикс в `project.yml`
   (`bundleIdPrefix` и `PRODUCT_BUNDLE_IDENTIFIER` обоих таргетов, напр.
   `com.<ваше-имя>.mcstatus`) и `xcodegen generate`.
6. Вверху Xcode выбрать устройство (iPhone, не симулятор). Первый раз Xcode несколько
   минут «готовит iPhone к разработке» — дождаться.
7. Run (⌘R). На телефоне: Настройки → Основные → VPN и управление устройством →
   ваш Apple ID → «Доверять». Run ещё раз.
8. По желанию — без кабеля: Window → Devices and Simulators → iPhone → «Connect via
   network» (Мак и телефон в одной Wi‑Fi).

Ограничения бесплатного Apple ID: сборка живёт **7 дней** (потом снова Run), до 3
приложений на устройстве, App Group нет — виджет настраивается вручную (п. 3.6).

### 2. Сервер

По умолчанию приложение ходит на `https://middle-corridor-weld.vercel.app` — Мак не
нужен, хватит интернета на телефоне. Пульт демо (перевод часов) — только со своим
бэкендом: Мак `MOCK_DATA=true DEMO_CONTROL=true .venv/bin/python -m app.main`,
в приложении Настройки → долгое нажатие на версию → «Сервер»
`http://<ipconfig getifaddr en0>:8000` → «Проверить связь»; на запрос «Локальная сеть» —
«Разрешить».

### 3. Финальный прогон (что проверить глазами)

1. Холодный старт: заставка → «Мои грузы».
2. Добавить MC-26-0398 → разрешить уведомления → карточка: вилка ETA, «Почему задержка»,
   карта (полноэкранная по нажатию), блок «Проверка санкций» внизу — «Совпадений нет».
3. Добавить **MC-26-0431** → сразу баннер «MC-26-0431: возможна санкционка»; в списке
   красная пометка «Санкции?», в карточке блок «Проверка санкций» наверху (сталь RU).
   Перезапустить приложение — баннер **не** повторяется.
4. Добавить MC-26-0412 → блок «Проверить вручную» (CHPL), баннера нет.
5. Настройки → «Уведомления»: пять переключателей, включая «Санкционные риски».
6. Виджет: домашний экран → долгое нажатие → «+» → Middle Corridor → «Изменить виджет»:
   номер MC-26-0398 (сервер — пусто, значит Vercel).
7. Карточка 0398 → «На экран блокировки» → заблокировать телефон: Live Activity.
8. С пультом (п. 2): долгое нажатие на версию → «Сброс истории»; **долгое нажатие двумя
   пальцами** в любом месте — следующий шаг, на экране ничего не всплывает, лёгкая
   вибрация; заблокировать сразу после шага → через 5 с уведомление «Шторм: Актау…».
   После «Сброса истории» флаг санкций у 0431 придёт снова (для живого показа).
9. Тёмная тема и крупный шрифт (Настройки iPhone): ничего не обрезается.
10. Что не так — скриншоты (экран, экран блокировки, Dynamic Island, виджет) и шаг.
