# mc-status — Middle Corridor Status

Оперативная сводка по **Среднему коридору (TITR)** — Китай → Казахстан → Каспий →
Кавказ → Чёрное море → Европа — в Telegram: публичный канал с алертами и бот
с интерактивом.

Продукт закрывает три боли операторов коридора:

1. **Непредсказуемость Каспия** — погодный предиктор остановки портов
   (Актау, Курык, Алят + Поти, Батуми, Констанца): пороги по устойчивому ветру
   и порывам, алерты `watch`/`warning`/`critical` с антиспамом и «отбоем».
2. **Отсутствие единого статуса** — `/status`: погодные алерты, позиции судов
   (честное «нет данных» при слабом покрытии AIS), свежие ручные сводки.
3. **Непрозрачность** — новостная лента коридора и данные от доверенных
   источников (очереди, ставки, простои на границах) в одном канале.

## Возможности

| Кому | Что |
|------|-----|
| Все | `/start`, `/help`, `/status`, `/status aktau` (по коду или названию порта) |
| Доверенные источники | `/report` — очередь ⚓️ / ставка 💰 / простой на границе 🚧 / заметка 📝; `/cancel` |
| Админы | `/poll_weather`, `/poll_news` — прогон погоды/новостей «по кнопке»; `/pending`, `/approve <id>`, `/reject <id>` — модерация; `/add_source <tg_id> <role> <имя>` — whitelist |

Публикации в канал: погодные алерты и отбои, новости (дедуп + троттлинг),
одобренные ручные сводки.

## Архитектура

```
Погода (Open-Meteo) ──▶ ┌────────────────────────┐
AIS (AISstream WS)  ──▶ │   services (ядро)      │ ──▶ PostgreSQL
Новости (RSS)       ──▶ │ predictor · tracker    │
Ручной ввод (бот)   ──▶ │ news · reports · status│
                        └──────────┬─────────────┘
                 ┌─────────────────┼──────────────────┐
                 ▼                 ▼                  ▼
          Telegram-бот      Публичный канал     FastAPI (:8000)
          (aiogram 3)       (publisher)         /health · /webhooks/vesselapi
```

Слои: `integrations/` (внешние API за Protocol-интерфейсами) → `services/`
(бизнес-логика, не знает про Telegram/HTTP) → `bot/`·`api/` (транспорт) →
`db/` (модели + репозитории). Подробнее для разработки — [CLAUDE.md](CLAUDE.md).

## Локальный запуск

Нужны: Python 3.11+, Docker.

```powershell
# 1. Postgres (порт 5433 — 5432 часто занят системным Postgres)
docker compose up -d db

# 2. Окружение
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"

# 3. Конфигурация
copy .env.example .env            # заполнить BOT_TOKEN, CHANNEL_ID, ADMIN_USER_IDS

# 4. Миграции (создают схему и сиды портов/судов)
alembic upgrade head

# 5. Запуск: API :8000 + бот + AIS-воркер
python -m app.main
```

Проверка: `GET http://localhost:8000/health` →
`{"status":"ok","db":true,"ais_last_message_age_s":...}`.

Джобы можно гонять и из терминала: `python -m app.scheduler.jobs weather|news`.

## Конфигурация (ENV)

Все параметры — через переменные окружения (`.env` локально, см.
[.env.example](.env.example)). Ключевые:

| Переменная | Значение |
|-----------|----------|
| `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_USER_IDS` | Telegram: бот, канал (бота — админом!), админы через запятую |
| `DATABASE_URL` | `postgresql+asyncpg://...` |
| `WEATHER_*_WIND/GUST` | пороги предиктора, м/с — **стартовые, калибровать по фактическим остановкам** |
| `AUTO_PUBLISH_REPORTS` | `false` = ручные сводки через модерацию `/approve` |
| `SCHEDULER_ENABLED` | `false` = погода/новости по командам админа; `true` = автопилот по интервалам |
| `NEWS_SOURCES` | RSS/Atom-ленты через запятую |
| `AISSTREAM_API_KEY`, `AIS_BBOX_*` | AIS-стрим и bounding box'ы |
| `VESSELAPI_WEBHOOK_SECRET` | пусто = вебхук `/webhooks/vesselapi` выключен |

## Деплой (Railway)

1. Подключить GitHub-репозиторий, Railway соберёт по [Dockerfile](Dockerfile)
   (конфиг — [railway.json](railway.json); миграции применяются на старте).
2. Добавить Postgres-плагин; проставить `DATABASE_URL`
   (заменить `postgresql://` на `postgresql+asyncpg://`).
3. Прописать ENV из [.env.example](.env.example).
4. Healthcheck — `/health`.

Один сервис = один процесс (API + бот + AIS). Второй инстанс бота запускать
нельзя (конфликт polling).

## Известные ограничения

- **AIS на Каспии почти слеп** (мало береговых приёмников — проверено вживую):
  статус судна без свежей позиции — «нет данных», а не «стоит». MMSI паромов
  ASCO в сидах пустые — заполняются руками по мере появления судов в эфире.
- **Пороги ветра не откалиброваны** — стартовые значения из спеки; уточнять
  по фактическим остановкам портов (в этом ядро ценности продукта).
- **middlecorridor.com без RSS** — официальный портал потребует
  скрейпер-реализацию `NewsProvider` (интерфейс готов).
- **VesselAPI-клиент не сверен** с боевой документацией тарифа — использовать
  после проверки формата ответов.
