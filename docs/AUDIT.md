# Аудит mc-status — сентябрь 2026

Срез: ветка `claude/project-audit-improvements-slsqbj` поверх `main` (91b0c19).
Методика:

- три независимых ревью кода: бэкенд, фронт, продукт/рынок;
- скриншоты интерфейса на моках: десктоп 1440/1280, планшет, Pixel 7, RU/EN,
  светлая подложка, replay, недоступный API;
- прогон на настоящем Postgres 16: миграции, `alembic check`, старт в боевом
  режиме;
- axe-core (WCAG 2.1 AA), pip-audit, npm audit, покрытие pytest.

## Коротко

Кодовая база зрелая для прототипа:

- слои из CLAUDE.md соблюдены: `services` не импортирует aiogram/fastapi,
  SQL живёт только в `db/repositories`;
- 136 тестов бэкенда (покрытие 83 %), 80 юнит-тестов фронта, 30+ e2e;
- известных уязвимостей в зависимостях нет;
- модели совпадают с миграциями на Postgres.

Главные риски не в коде, а в эксплуатации:

- публичный API, бот и алерты живут в одном процессе и делят один пул БД;
- публикации в канал уходят до коммита;
- replay в боевом режиме выдаёт текущие алерты за исторические.

Интерфейс держался на глазах разработчика, поэтому визуальные баги доезжали до
main. Теперь их ловят геометрические проверки в CI.

### Бэкенд (у каждого исправления — тест)

- `/status <b` ронял ответ бота («can't parse entities»), `<a href>`
  отражался пользователю. Теперь экранируются ввод пользователя, текст
  ошибок, названия портов и сообщения алертов в HTML Telegram.
- Вебхук Telegram ждал `feed_update`:
  - исключение хендлера давало 500, и Telegram слал апдейт повторно;
  - `/poll_news` дольше 60 с запускала второй прогон.
  
  Теперь обработка идёт в фоне, ответ 200 уходит сразу, секреты сверяются
  через `hmac.compare_digest`. VesselAPI проверяет секрет до разбора тела.
- RSS: `external_id` > 256, `url` > 1024 или схема не http(s) (например
  `javascript:`) — такие записи отбрасываются или обрезаются. Раньше на
  Postgres одна длинная запись роняла коммит всех источников.
- `title_ru` от LLM обрезается до 512 символов. Раньше коммит падал ПОСЛЕ
  публикации, и новость уходила в канал на каждом прогоне.
- `/poll_weather` и `/poll_news` админа больше не идут параллельно
  планировщику: `asyncio.Lock`. Раньше выходили двойные алерты и посты.
- Снимок карты: агрегатор статуса вызывается раз в 2 с, а не трижды на
  снимок. Было 82 SQL-запроса на снимок.
- Ленивое обновление ветра: после ошибки Open-Meteo пауза 10 минут. Раньше
  каждый запрос `/wind` висел ~36 с и сжигал квоту.
- `at=9999-12-31T23:59:59-14:00` давал 500, теперь 400.
- Таймаут Anthropic 30 с вместо 600. `logger.exception` вместо потерянных
  трейсбеков. Закрывается httpx-клиент Open-Meteo сетки.
- Ops:
  - Docker работает без root, с `HEALTHCHECK`;
  - добавлен `.dockerignore`: раньше в контекст сборки уходили `.env` с
    боевыми ключами и `node_modules`;
  - `.env` добавлен в `.vercelignore`.

### Предлагаемая схема токенов (F1)

```
примитивы:   --gray-0…9, --green-5, --amber-5, --orange-5, --red-5, --violet-5, --blue-5
поверхности: --surface-0 (фон) / -1 (панель) / -2 (карточка) / -overlay
текст:       --text-1 / -2 / -3 (muted) / -inverse
границы:     --border-subtle / --border-strong / --focus
статусы:     --status-{ok,watch,warning,critical}{,-text,-bg}   (-bg через color-mix())
домен:       --corridor, --cargo, --vessel, --wind-{0..5}, --replay
шкалы:       --radius-{sm,md,lg,pill} = 4/8/12/999
             --fs-{2xs,xs,sm,md,lg,xl} = 10/11/12/13/15/18
             --space-{1..6} = 4/6/8/12/16/24
             --shadow-{1,2}, --z-{map,overlay,sheet,toast}
```

Сделано проще, без `tokens.ts` и числовых примитивов. Семантические имена живут
прямо в `styles.css` (`--panel`, `--text`, `--warning-text`, `--map-label`…), а
TS ссылается на них строками `var(--…)` (`LEVEL_TEXT`). Тест `styles.test.ts`
проверяет, что цветовые литералы есть только в блоках, состоящих из одних
custom properties.

## UI-проход (после аудита)

По итерациям «правка → скриншот → разбор», галерея — `e2e/screens.spec.ts`:

- **Карта.** Карта — главный элемент экрана:
  - топбар в одну строку (цифры крупнее, статус короче);
  - слои, подложка, ветер и легенда свёрнуты за кнопками «Слои» и «Легенда»;
  - стартовый кадр — Каспий и Кавказ, а не весь коридор мелко.
- **Подписи.** Больше не налезают друг на друга (F3). Паромы стали нейтрального цвета: оранжевый значил и «паром», и «риск остановки».
- **Карточка груза.**
  - действия — строкой кнопок;
  - у графика задержек концы маршрута, подсказки по наведению и легенда;
  - убрана строка ветра, дублировавшая соседнюю.
- **Телефон.**
  - топбар в две строки, статус виден только при проблеме;
  - шкала времени в одну строку, скорость воспроизведения по умолчанию;
  - панели не уходят под шторку.
- **Подсказка для новичка** при первом визите: что это и куда нажимать.
- **Шкала времени.** В живом режиме — отметка LIVE вместо «сейчас» с неактивной кнопкой рядом.
- **Контролы.** Кнопки зума и компаса читаются на тёмной подложке. Токены шкал (`--fs-*`, `--radius-*`, `--shadow-panel`) — первый шаг F1.

## Светлая тема и доступность

- **Токены.** В CSS не осталось цветов вне блоков токенов. Тема меняет значения, а не селекторы:
  - заливки статусов общие;
  - текстовые варианты (`--warning-text` и т. п.) свои у каждой темы — контраст AA на белом.
- **Карта следует подложке, а не теме.** Подписи и ореолы маркеров берут `--map-*` от `.map[data-basemap]`:
  - на спутнике в светлой теме подписи остаются светлыми;
  - стрелки и частицы ветра на светлой подложке — синие (белые пропадали).
- **Тема.** По умолчанию — как в системе, кнопка ☀/☾ в топбаре. Применяется до первого рендера — без вспышки тёмного фона.
- **Клавиатура и скринридер:**
  - «К списку грузов» — первая по Tab;
  - при открытии карточки фокус на её номере, «← все грузы» возвращает фокус на строку списка;
  - заголовки h2/h3;
  - вкладки связаны с панелью (`aria-controls` / `tabpanel`).
- **Проверки.** axe (`a11y.spec.ts`) — в обеих темах, с открытыми слоями и легендой. Светлые экраны — в галерее `screens.spec.ts` (`light-*`). Playwright закреплён на `colorScheme: "dark"`: без настройки он эмулирует светлую систему.
