# iOS-приложение — видение и план демо

Итог интервью с владельцем продукта. Документ — опора для первой версии; что
не вошло сюда, в демо не делаем.

## Решения

| Вопрос | Решение |
|---|---|
| Для кого | Для всех, кто следит за коридором: публичное приложение без входа |
| Как груз попадает в список | По ссылке от оператора (deep link) или вводом номера |
| Первый экран | «Мои грузы»; пока список пуст — состояние коридора и кнопка «Добавить груз» |
| Уведомления | Шторм в порту на пути груза · событие по грузу · задержка растёт · прогноз выхода из очереди |
| Фишки iOS в v1 | Live Activity (экран блокировки, Dynamic Island) · виджет · офлайн |
| Формат | Нативное приложение (SwiftUI), в перспективе App Store |
| Вид | Как родное iOS-приложение: системные списки и шрифты, светлая/тёмная тема системы; цвета статусов — как на сайте |
| Языки | Русский, английский |
| Деньги | Пока бесплатно |
| Цель первой версии | Демо для инвестора/партнёра на моках, через 2–4 недели |
| Фокус демо | История одного груза |
| Окружение | Аккаунта Apple Developer нет; есть Mac — сборка и запуск через него |

## Сценарий демо (≈2 минуты)

1. Открыли приложение: списка нет — видно состояние коридора (порты с риском
   шторма, очередь в Актау) и «Добавить груз».
2. Открыли ссылку от оператора → груз в списке: маршрут, где сейчас, ETA.
3. Заблокировали телефон → Live Activity: «Курык → паром → Алят, ETA 06.10».
4. Пуш: «Шторм в Актау: швартовка закрыта, ваш груз в очереди».
5. Карточка груза: «выход из очереди через 2–3 дня (до 5 в плохом сценарии)».
6. Виджет на домашнем экране — статус груза без открытия приложения.
7. Перематываем мок вперёд: груз погружен, вышел, доставлен — Live Activity
   закрывается.

## Экраны v1

- **Мои грузы** — карточки: номер, маршрут, статус и задержка (цвета как на
  сайте), прогресс. Свайп — удалить. Пустое состояние — сводка коридора.
- **Добавить груз** — поле номера (+ вставка из буфера), открытие по ссылке
  `https://<домен>/?s=<номер>` (Universal Link) и `mcstatus://s/<номер>`.
- **Карточка груза** — карта маршрута (MapKit; подтверждённое — сплошным,
  проекция — пунктиром, как на сайте), «сейчас», погода в ближайшем порту,
  прогноз очереди, точки маршрута, «поделиться».
- **Коридор** — порты с уровнем риска и ветром, новости.
- **Настройки** — какие уведомления присылать, язык.

## Техника

- **Данные** — тот же `/api/v1`: `/snapshot` (коридор, порты, новости),
  `/shipments/{ref}` (груз). Демо — против бэкенда с `MOCK_DATA=true`.
- **Офлайн** — последний ответ по каждому грузу и снимок коридора хранятся на
  устройстве (SwiftData); без сети — данные с пометкой «обновлено N мин назад».
- **Виджет и Live Activity** — WidgetKit/ActivityKit, общий App Group с
  приложением. В демо Live Activity обновляет само приложение и симулятор
  (`xcrun simctl push` с файлом .apns) — платный аккаунт Apple не нужен.
- **Пуши в боевом режиме** — APNs; нужен Apple Developer ($99/год) и на
  бэкенде регистрация устройств с подписками на грузы и порты. Не в демо.
- **Прогноз выхода из очереди** — на бэкенде (место в очереди ÷ отгрузка в
  сутки + простой по погоде, вилка P50/P90); в демо — из мока.
- **Карта** — MapKit: родной вид, без ключей и стороннего SDK. Частицы ветра
  с сайта в v1 не переносим.

## Технические решения (сессия 31.10.2026)

| Вопрос | Решение |
|---|---|
| Сборка и тесты | Mac подключён к облачной сессии через Remote Control: `xcodebuild`, симулятор и скриншоты запускает агент |
| Минимальная iOS | 17 (SwiftData, Observation, интерактивные виджеты, Live Activity) |
| Проект | XcodeGen: `ios/project.yml` в git, `.xcodeproj` генерируется и в git не попадает |
| Устройства | Симулятор + свой iPhone (бесплатный Apple ID: переподпись раз в 7 дней) |
| Бэкенд демо | Локально на Маке, `MOCK_DATA=true`; симулятор — `localhost:8000`, iPhone — IP Мака в той же Wi‑Fi; адрес меняется в настройках приложения |
| Bundle ID | `com.malakhouski.mcstatus`, на экране — «Middle Corridor» |

Риск: бесплатный Apple ID не даёт App Groups/Associated Domains на устройстве.
Поэтому виджет умеет сам сходить в `/api/v1`, если общий контейнер недоступен,
а Universal Links ждут платного аккаунта (до тех пор — `mcstatus://`).

## Чего нет в v1

Вход и аккаунты компаний, закрытые грузы оператора, оплата, ввод событий
диспетчером, публикация в App Store, казахский/азербайджанский/китайский.

## Что нужно от владельца

1. Mac с Xcode, подключённый к сессии через Remote Control (папка-репозиторий),
   — сборка, симулятор и скриншоты.
2. Позже — аккаунт Apple Developer: TestFlight, реальные пуши, App Store.
3. Название и иконка (до тех пор — «Middle Corridor»).
