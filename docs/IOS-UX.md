# iOS — аудит UX/UI и что из него сделано

Аудит от 01.11.2026 по коду `e55920b`. Полная версия с токенами, брендбуком, чек-листом
современных критериев и макетами «сейчас / предлагаю» — в дизайн-системе «Middle Corridor iOS»
(артефакт claude.ai владельца). Здесь — выжимка и статус по пунктам.

**Шкала:** P1 — мешает главной задаче или заметно на демо; P2 — неудобство, HIG, доступность;
P3 — полировка. ✓ — сделано в ветке `claude/exciting-keller-16j706`, ◻ — бэклог.

## Иконка

Прежняя иконка (восходящая ломаная с точками на зелёном) читалась как график акций. Из пяти
концептов (паром, Каспий, контейнер, ветроуказатель, маяк — карточка AppIcon дизайн-системы)
выбран **«Каспий»**: силуэт моря, рельсы с двух берегов, переправа Актау → Алят точками, паром
«где сейчас» — амберное кольцо. Варианты для iOS 18+: обычный, тёмный и тонированный
(`AppIcon.appiconset`, генератор — `ios/scripts/make_icon.swift`). ✓

## Бэклог из аудита

- App Intents: «Где мой груз?», грузы в Spotlight.
- Universal Links после покупки аккаунта Apple Developer — та же https-ссылка откроет приложение.
- Сканер номера с накладной или QR (`DataScannerViewController`).
- `Tab` API iOS 18 и `tabBarMinimizeBehavior` под iOS 26.
