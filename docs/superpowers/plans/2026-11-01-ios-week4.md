# iOS, неделя 4 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести приложение до показа: отложенные мелочи ревью, тёмная тема и крупный шрифт без обрезок, иконка, сценарий для ведущего и видео демо.

**Architecture:** Правки точечные в существующих слоях (мок-бэкенд, MCCore, экраны). Иконка рисуется скриптом CoreGraphics (воспроизводимо, без внешних редакторов). Видео пишет `xcrun simctl io recordVideo`, а сценарий ведёт XCUITest `DemoScenarioTests`: он сам дергает `/api/v1/demo/clock` по HTTP (тест-раннер видит `localhost` Мака), поэтому пульт в кадр не попадает.

**Tech Stack:** Python 3.11/pytest, Swift 6, SwiftUI, XCTest/XCUITest, CoreGraphics (скрипт), `simctl`.

**Spec:** `docs/superpowers/specs/2026-10-31-ios-weeks-2-4-design.md` (раздел 8, «Неделя 4»); отложенные находки — `Final: minor (deferred)` в журнале недели 2 (M2–M8).

## Global Constraints

- Всё из Global Constraints недель 2–3 (iOS 17, Swift 6 strict, MCCore без UI, `DEMO_CONTROL` только локально, строки RU/EN, цвета — `Theme`).
- Видео и скриншоты — в `ios/build/` (не в git).
- `DemoScenarioTests` пропускается (`XCTSkip`) без переменной окружения `MC_DEMO_VIDEO=1` (передаётся как `TEST_RUNNER_MC_DEMO_VIDEO=1`) — обычный прогон UI-тестов бэкенд не требует.

## Review Focus

1. Смена адреса сервера при кэше от старого сервера — данные старого не показываются как свежие → тест в Task 1.
2. `advance` на огромное число часов — 422, часы не ломаются → тест в Task 1.
3. Тёмная тема: белый текст на кнопке «Добавить груз» читается (контраст ≥ 4.5) → правка + скриншот в Task 2.
4. Крупный шрифт (Accessibility L): карточка и список без обрезанного текста → скриншот в Task 2.
5. Видео-сценарий упал посреди (бэкенд недоступен) — тест падает понятно, а не висит → `XCTSkip`/таймауты в Task 4.
