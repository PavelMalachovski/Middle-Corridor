# iOS, неделя 3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Уведомления четырёх видов, Live Activity (экран блокировки + Dynamic Island) и виджет — работают и на симуляторе, и на iPhone с бесплатным Apple ID.

**Architecture:** Правила уведомлений и «живой статус» груза — чистые функции в MCCore (`swift test`). `TrackedShipments` сообщает об изменениях после каждого обновления; приложение превращает их в локальные уведомления (`UNUserNotificationCenter`) и обновляет Live Activity. Новый таргет-расширение `MiddleCorridorWidgets` (WidgetKit + ActivityKit) делит с приложением папку `Shared/` (атрибуты Live Activity, вид статуса) и MCCore. App Group — только в сборках под симулятор; на iPhone виджет настраивается номером и адресом сервера сам.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, UserNotifications, ActivityKit, WidgetKit, AppIntents, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-31-ios-weeks-2-4-design.md` (разделы 5, 6, «Порядок работ» — неделя 3); правила — `CLAUDE.md`. Решения владельца: показ и на iPhone, и на симуляторе; Live Activity — по кнопке; виджет — один груз; все спорные параметры — рекомендованные.

## Global Constraints

- iOS 17.0, Swift 6, `SWIFT_STRICT_CONCURRENCY=complete`, без предупреждений concurrency; MCCore не импортирует SwiftUI/UIKit/ActivityKit/WidgetKit/UserNotifications.
- Bundle ID приложения `com.malakhouski.mcstatus`, расширения — `com.malakhouski.mcstatus.widgets`; App Group `group.com.malakhouski.mcstatus` — **только** `CODE_SIGN_ENTITLEMENTS[sdk=iphonesimulator*]`; сборка для устройства — без entitlements App Group.
- Без APNs: Live Activity обновляет приложение (`pushType: nil`); уведомления — локальные.
- Первая загрузка груза уведомлений не даёт; пороги: задержка выросла на ≥ 3 ч; прогноз очереди сдвинулся на ≥ 12 ч; шторм — уровень порта на пути (от текущего узла включительно) вырос и стал ≥ warning.
- Строки — RU/EN (MCCore `Strings` для текстов уведомлений и Live Activity; приложение — `Localizable.xcstrings`); у элементов UI-тестов — `accessibilityIdentifier`.
- Запрос разрешения на уведомления — после первого успешного добавления груза (не на старте: на демо системный диалог на шаге 1 мешает).
- iOS-команды — с `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`, симулятор `iPhone 17`; после `project.yml` — `xcodegen generate`.

## Review Focus

1. Порт был `warning` и стал `critical` (история 0398: риск → шторм) — уведомление «шторм» приходит (эскалация), а `critical → critical` и `critical → warning` — нет → тест в Task 1.
2. Груз удалён из списка или стал «не найден» между обновлениями — правила не падают и молчат → тест в Task 1.
3. Live Activity для груза, который доставлен, — финальное состояние и закрытие, повторный старт не плодит вторую активность → тест в Task 4 (MCCore: `LiveStatus` для delivered) + ручная проверка.
4. Виджет без App Group и без настроенного номера — «Выберите груз в настройках виджета», а не пустота/краш → тест в Task 5 (`WidgetModel`).
5. Обновление отменено (уход с экрана) — изменений не публикуется, уведомлений нет → тест в Task 2.

### Task 1: MCCore — правила уведомлений

**Files:** Create `ios/MCCore/Sources/MCCore/NotificationRules.swift`; Modify `Strings.swift`; Test `NotificationRulesTests.swift`.

**Interfaces — Produces:**
- `public enum NoticeKind: String, CaseIterable, Sendable { case storm, event, delay, queue }`
- `public struct NotifySettings: Sendable, Equatable { var storm, event, delay, queue: Bool; static let all; func allows(_ kind: NoticeKind) -> Bool }`
- `public struct AppNotice: Sendable, Equatable, Identifiable { let id: String; let kind: NoticeKind; let ref: String; let title: String; let body: String }` — `id` детерминирован (`"\(kind)-\(ref)-\(fingerprint)"`), чтобы одно и то же событие не пришло дважды.
- `public enum NotificationRules { static func diff(old: [String: Shipment], new: [String: Shipment], oldNodes: [NodeStatus], newNodes: [NodeStatus], settings: NotifySettings, labels: Labels) -> [AppNotice] }`
  - event: `old.lastEventAt != new.lastEventAt` → title `"{ref}: {labels.event(new)}"`, body — `labels.route` + ETA.
  - delay: `new.delayHours − old.delayHours ≥ 3` и `new.isDelayed` → «Задержка {ref} выросла до +{h}».
  - storm: порты на пути (стоит — `position.fromCode`, плюс `checkpoints` не `done`), у которых `rank(new) > rank(old)` и `new ≥ warning` → «Шторм в {порт}: {уровень}», body «Груз {ref} в очереди в порту» если стоит в этом порту, иначе «Порт на пути груза {ref}».
  - queue: `old.queue == nil && new.queue != nil`, или `|Δ p50| ≥ 12` → «Выход из очереди {ref}: {main}», body «в плохом сценарии — {worst}».
  - Номер без старых данных (первая загрузка) — ничего.
