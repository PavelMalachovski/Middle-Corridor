# iOS, неделя 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативное приложение «Middle Corridor» (SwiftUI, iOS 17+): «Мои грузы», добавление груза по номеру и ссылке, карточка груза, RU/EN — против `/api/v1` мок-бэкенда на Маке.

**Architecture:** Вся логика без UI — локальный Swift Package `ios/MCCore` (модели `/api/v1`, HTTP-клиент, разбор номера/ссылки, подписи из кодов бэкенда, хранилище отслеживаемых грузов); тесты — `swift test` на Маке, без симулятора. Приложение `ios/App` — тонкий SwiftUI-слой поверх MCCore. Проект описан в `ios/project.yml` (XcodeGen), `.xcodeproj` генерируется и в git не попадает. Сборка и тесты идут на Маке пользователя через Remote Control.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, Observation (`@Observable`), XCTest/Swift Testing, XcodeGen, String Catalog (`Localizable.xcstrings`).

**Spec:** `docs/IOS.md` (решения, экраны v1, «Технические решения»); формы данных — `app/services/map_snapshot.py`, `app/services/tracking.py`; подписи из кодов — `web/src/i18n/labels.ts`, `web/src/i18n/{ru,en}.ts`.

## Global Constraints

- Минимальная iOS — 17.0; Bundle ID — `com.malakhouski.mcstatus`; имя на экране — «Middle Corridor».
- Проект — только через `ios/project.yml`; `ios/*.xcodeproj` в `.gitignore`.
- Данные — только `/api/v1` (`/snapshot`, `/shipments/{ref}`); бэкенд демо — `MOCK_DATA=true` на Маке, `:8000`.
- Адрес сервера по умолчанию `http://localhost:8000` (симулятор); на iPhone — IP Мака в той же Wi‑Fi, задаётся в настройках приложения.
- Языки — ru и en; по умолчанию системный, явный выбор хранится в `UserDefaults` (`mc.lang` = `system|ru|en`).
- Бэкенд отдаёт КОДЫ рядом с русской строкой: в EN подпись собирается из кода (как `web/src/i18n/labels.ts`); без кода остаётся русская строка.
- Положение без живой позиции — ПРОЕКЦИЯ (`position.confirmed == false`): так и подписывать («оценка по расписанию»), не как факт.
- Цвета статусов — как на сайте (`web/src/styles.css`): ok `#0ca30c`, watch `#fab219`, warning `#ec835a`, critical `#d03b3b`, нейтральный `#6b6b66`; в тексте на светлом фоне — тёмные `*-text` (`#0f7a33`, `#8a5a00`, `#b24a1c`, `#b42318`). Задержка считается, если `delay_hours >= 1 && state != delivered`.
- Вид — системные списки и шрифты, светлая/тёмная тема системы, Dynamic Type.
- MCCore не импортирует SwiftUI/UIKit.

## Review Focus

1. Время с микросекундами `2026-10-31T11:08:54.312620Z` и без дробной части `2026-10-31T11:00:00Z` — оба разбираются (стандартный `ISO8601DateFormatter` 6 знаков не умеет) → тест в Task 2.
2. Новый код состояния/события/причины от бэкенда (например `state: "cancelled"`) — карточка не падает, показывает русскую строку или код → тест в Task 2 (декод) и Task 4 (подпись).
3. Номер, вставленный с мусором: `" mc-26-0412\n"`, ссылка `https://x.app/?s=MC-26-0412&view=map`, `mcstatus://s/mc-26-0412`, текст письма «ваш груз MC-26-0412 отправлен» → нормализуется в `MC-26-0412` → тест в Task 3.
4. Сервер недоступен (Мак спит, другая Wi‑Fi) — список показывает последние данные и ошибку, а не пустоту; добавление не теряет введённый номер → тесты в Task 5.
5. Один и тот же груз добавлен дважды в разном регистре или по ссылке и вручную — в списке один → тест в Task 5.

### Task 5: API-клиент и «Мои грузы» (хранилище)

**Files:**
- Create: `ios/MCCore/Sources/MCCore/CorridorAPI.swift`, `ios/MCCore/Sources/MCCore/TrackedShipments.swift`
- Test: `ios/MCCore/Tests/MCCoreTests/CorridorAPITests.swift`, `ios/MCCore/Tests/MCCoreTests/TrackedShipmentsTests.swift`

**Interfaces:**
- Consumes: модели и `APIDate.decoder` (Task 2), `ShipmentRef.parse` (Task 3).
- Produces: `public protocol CorridorAPI: Sendable { func snapshot() async throws -> MapSnapshot; func shipment(ref: String) async throws -> Shipment }`
- Produces: `public struct HTTPCorridorAPI: CorridorAPI { init(baseURL: URL, session: URLSession = .shared) }` — `GET {base}/api/v1/snapshot`, `GET {base}/api/v1/shipments/{ref}` (ref percent-encoded), таймаут 10 с.
- Produces: `public enum APIError: Error, Equatable { notFound, http(Int), offline, decoding(String) }` (`URLError` → `.offline`).
- Produces: `public protocol RefStorage: Sendable { func load() -> [String]; func save(_ refs: [String]) }`, `public struct UserDefaultsRefStorage: RefStorage` (ключ `mc.tracked`).
- Produces: `@MainActor @Observable public final class TrackedShipments { init(api: CorridorAPI, storage: RefStorage); private(set) var refs: [String]; private(set) var shipments: [String: Shipment]; private(set) var snapshot: MapSnapshot?; private(set) var lastError: APIError?; private(set) var updatedAt: Date?; func add(_ input: String) async throws -> String; func remove(_ ref: String); func refresh() async }`
  - `add`: `ShipmentRef.parse` (`nil` → `throw AddError.invalidRef`), уже есть → вернуть ref без запроса, иначе `api.shipment`; `notFound` → `throw AddError.notFound`, сеть → `throw AddError.offline`; при успехе ref вставляется в начало списка и сохраняется.
  - `refresh`: snapshot + все грузы параллельно (`withTaskGroup`); ошибка не стирает старые данные, кладётся в `lastError`; `updatedAt` — только при успехе.
- Produces: `public enum AddError: Error, Equatable { invalidRef, notFound, offline }`

- [ ] **Step 2: Тесты хранилища** (фейковые `CorridorAPI` и `RefStorage` в памяти): `test_addNormalizesAndPersists` (`" mc-26-0412 "` → refs `["MC-26-0412"]`, storage сохранил); `test_addTwiceDifferentCase_keepsOne`; `test_addUnknown_throwsNotFound_andStoresNothing`; `test_addInvalid_throwsInvalidRef_noRequest`; `test_remove`; `test_refreshOffline_keepsOldData` (после успешного refresh API падает с `.offline` → `shipments` прежние, `lastError == .offline`, `updatedAt` не изменился); `test_loadsRefsFromStorageOnInit`.
