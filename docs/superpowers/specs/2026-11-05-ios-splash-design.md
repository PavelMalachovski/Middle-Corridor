# iOS: заставка «Переправа» — дизайн

Владелец выбрал вариант B из трёх макетов (A — статичная иконка, B — переправа, C — весь
коридор). Подписи на заставке — только английские.

## Зачем

Сейчас `UILaunchScreen: {}` — при запуске пустой белый/чёрный экран. Заставка продолжает иконку
«Каспий», на которую человек только что нажал: паром идёт через море — суть продукта. Нужна и для
демо инвестору, и как «лицо» приложения.

## Что видит человек

1. Нажал на иконку → системный экран запуска: фирменный тёмно-зелёный фон, по центру Каспий с
   точками переправы и кружками портов Актау и Алят (без рельсов и парома). Статичный — так
   устроен iOS.
2. Приложение поднялось → поверх него тот же кадр, и он оживает (≈1,75 с):
   - 0–0,45 с — рельсы «приходят» от краёв экрана к портам (с востока — в Актау, с запада — в Алят);
   - 0,35–1,15 с — паром (амберное кольцо) появляется в Актау и идёт в Алят;
   - 0,8–1,15 с — под морем проявляется «Middle Corridor» и «Aktau → Alat»;
   - 1,45–1,75 с — заставка растворяется, под ней «Мои грузы».

## Правила

- Только холодный старт: живёт в `AppModel` процесса; возврат из фона — без заставки.
- Открыли по ссылке, из виджета, Live Activity или уведомления — заставка сразу уходит, виден груз.
- Тап по заставке — быстрое растворение (0,2 с).
- «Уменьшение движения» или VoiceOver — без анимации: после статичного экрана запуска сразу
  приложение.
- Текст — `Text(verbatim:)`, только английский, в каталог строк не попадает.
- Фон один в обеих темах; статус-бар скрыт на экране запуска и во время заставки — иначе в
  светлой теме тёмный текст на тёмно-зелёном.
- UI-тесты: `-mc.splash NO` выключает заставку (смоук не ждёт 1,75 с); отдельный тест проверяет,
  что заставка есть и уходит.

## Подходы

| Подход | Плюсы | Минусы |
|---|---|---|
| **Картинка запуска из того же SwiftUI-кода** (выбран) | Первый кадр анимации совпадает с экраном запуска до пикселя; один источник геометрии | Скрипт рендера (`ImageRenderer` на macOS), PNG надо перегенерировать при правке эмблемы |
| Экран запуска — только цвет, эмблема проявляется в приложении | Ни картинок, ни скрипта | Иконка «раскрывается» в пустой зелёный экран, а эмблема появляется с опозданием — пропадает связь с иконкой |
| Отдельный скрипт CoreGraphics, как `make_icon.swift` | Привычно для репозитория | Две копии геометрии (скрипт и SwiftUI) — рельсы разойдутся с кружками портов |

## Как устроено (решения исполнителя)

- `ios/App/Splash/CaspianEmblem.swift` — эмблема на чистом SwiftUI (без UIKit и MCCore, чтобы
  компилировалась и под macOS): берег, проекция, порты — те же числа, что в `make_icon.swift`.
- `ios/App/Splash/SplashView.swift` — оверлей: фон, эмблема, рельсы (`trim`), паром, подпись;
  кадр по времени из `SplashTimeline`.
- `ios/MCCore/.../SplashTimeline.swift` — чистая логика: прогресс рельсов/парома/подписи,
  прозрачность, пропуск тапом, конец. Тесты — `swift test`.
- `ios/scripts/make_launch/main.swift` — рендерит `CaspianEmblem` в `LaunchEmblem.imageset`
  (@1x/@2x/@3x); цвет `LaunchBackground` — `#072A24` (низ градиента иконки).
- `project.yml`: `UILaunchScreen: {UIColorName: LaunchBackground, UIImageName: LaunchEmblem}`,
  `UIStatusBarHidden: true`.
