# Маршрут Европа → Казахстан и санкции с учётом направления — дизайн (короткий)

Дата: 10.11.2026. Основа — реальные документы перевозки Škoda (Млада-Болеслав → Костанай,
июнь 2024 и 2026): букинг Maersk, экспортная декларация ЕС, инвойс, СМГС. Данные клиентов в
репозиторий не попадают — демо обезличено, коды ТН ВЭД взяты из декларации.

## Зачем
Первый реальный поток идёт **на восток**, а модель знала только «Китай → Европа». Санкции на нём
ошибались: чешский крепёж (7318, 7320, 7326) получал «проверить вручную — происхождение стали»,
хотя запрет ввоза прил. XVII касается ввоза **в ЕС**, а груз из ЕС вывозится.

## Решения владельца
- Строим маршрут и санкции (загрузка PDF — следующим шагом).
- Прил. XXIII (запрет экспорта промтоваров в РФ) — **добавить сейчас**.
- Демо — **два восточных груза**: на пароме Баку → Актау («чисто») и в Чёрном море (разъёмы
  из CHPL → «проверить вручную»).

## Как устроено
- **Узлы:** `MLADA_BOLESLAV` (CZ, ж/д), `KOPER` (SI, порт), `AMBARLI` (TR, порт), `KOSTANAY`
  (KZ, ж/д). **Плечи:** Млада-Болеслав → Копер (ж/д), Копер → Амбарлы (море, вокруг Греции),
  Амбарлы → Поти (Босфор, Чёрное море), Бейнеу → Костанай (ж/д, через Кандыагаш и Хромтау).
  Середина (Поти → … → Баку → Актау → Бейнеу) — существующие плечи в обратную сторону.
- **Список `eu_833_2014_export`** — прил. XXIII, 514 строк с EUR-Lex (консолидация 24.07.2026,
  сверено по контрольной сумме; 10 кодов в приложении повторяются — дубли схлопывает загрузчик).
  Мера — запрет экспорта, страна — RU (РБ — отдельный регламент 765/2006).
- **Направление.** Запрет ввоза (прил. XVII, XXI) применяется, только если страна назначения в ЕС
  (не указана — применяется, как раньше). Запрет экспорта: сильное — получатель/назначение
  RU/BY; без такой связи «проверить вручную» даёт **только CHPL** (флаг списка
  `review_code_only`), прил. XXIII без связи с РФ — не совпадение (оно покрывает почти любые
  автозапчасти, станки и электронику — иначе «проверить вручную» на каждом контейнере Škoda).
- Совпадения одной позиции с одной записью списка не дублируются.

## Не-цели
Загрузка PDF/OCR, флаг опасного груза (UN 2800) в карточке, регламент 765/2006 (Беларусь),
боевой источник отправок.
